# Snow Privacy Policy

Effective date: June 7, 2026

Snow is a Chrome extension that lets users transcribe audio from the current browser tab and download the transcript as a `.txt` file.

## Single Purpose

Snow's single purpose is to capture audio from the user's current browser tab, transcribe it locally in the browser, and let the user download or clear the transcript.

## Data Snow Handles

Snow may handle the following data:

- Current tab audio, used for local transcription.
- Transcript text generated from the current tab audio.
- Current tab title and URL, used to label the transcript file/session.
- Session metadata such as start time, stop time, transcript segments, and model name.

## How Data Is Used

Snow uses this data only to provide local browser-tab transcription and transcript download functionality.

## Local Storage

Transcript text and session metadata may be stored locally in the user's browser using Chrome extension storage. Users can clear this data from inside the extension.

## Audio and Transcript Uploads

Snow does not upload user audio or transcript content to our servers.

Snow may connect to Hugging Face domains to download open-source machine learning model files and related model data required for local browser-based transcription. These model files are used to run transcription locally in the browser.

## Data Sharing

Snow does not sell user data.

Snow does not transfer user audio, transcripts, or browsing data to third parties for advertising, analytics, profiling, creditworthiness, or unrelated purposes.

## Account Requirement

Snow does not require users to create an account.
